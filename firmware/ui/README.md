# ui

The drawing kit: a 1-bit canvas, its 5x7 font, and the marks that look the same on any glass. No page and no glass size lives here.

The 5x7 font is the HD44780U character set, ROM code A00, copied from Table 4 of Hitachi's datasheet. `NOTICE.md` credits it.

`Canvas` carries its width and height and draws on bytes it does not own. `Bitmap<W,H>` owns its bytes, at any size. A glass is declared where its size is known: `boards/<board>/glass.h` states what is soldered on, a product names it (`products/skyblip_go/glass.h` is `ui::Bitmap<200,200>`), the driver states what it can drive (`parts::Ssd1681::kGlassWidth`), and the board asserts the two equal.

The size is not a constant here because `make test` links every product into one binary, so a global width would break the day two products carry different glass. A runtime width costs a multiply per row on a panel that refreshes once a second.

Pages belong to their product (`products/skyblip_go/pages/`), and so does what a press means (`products/skyblip_go/input/`). Contact conditioning is `core/input/`.

| File | What it is |
|---|---|
| `canvas.h`, `canvas.cpp` | the surface, the primitives, the font |
| `widgets/wordmark.*` | the skyBlip wordmark, generated by `scripts/make_wordmark.py` |
| `widgets/mark.*` | the blip dot and its two arcs, at two sizes, in integers from `server/public/icon.svg` |
| `widgets/skyship.*` | the ownship symbol, written by `bin/rails ownship:compile` from `server/content/ownships/` |
| `widgets/blip.*` | the traffic blip: a diamond, or the mark pointing up or down, at two sizes, or a ring for no altitude, with its caret |

The ownship hot spot is the row where the aircraft is, on the wing, not the centre of the bounding box. Centring the box put a target 20 px abeam 11 degrees off its bearing, twice DO-257A's 1% guidance. The symbol is an even width, so it straddles the centre of the 200x200 glass between pixels 99 and 100.

Nothing here includes a framework header, so the host suite and the WASM simulator build.
