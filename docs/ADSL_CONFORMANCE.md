# ADS-L conformance

skyBlip's ADS-L implementation 0.1.0, read against ADS-L 4 SRD-860 Issue 2 clause by clause by the host test suite. Each of the specification's 80 clause headings is below, in the document's order, with the cases that read it: 170 pass and 20 are skipped (8 prose, 2 paperwork, 8 optional, 2 unmeasured).

Each claim names the file that checks it, under `firmware/`. A file under `protocols/adsl/test/conformance/` belongs to the component, which builds and passes on its own and goes with any copy of the stack (`firmware/protocols/README.md`, Taking a stack into another project). A file under `test/adsl/` needs skyBlip around the stack, because it checks skyBlip's choices, which a copy replaces with its own. A skipped case is a clause this device makes no claim on, and says why: prose, paperwork, optional, not implemented or unmeasured (`firmware/test/adsl/README.md`). Quoted prose is the comment the case carries.

Generated by `scripts/conformance.py adsl` from the run itself, and diffed in CI. Do not edit: rename the test case, or rewrite the comment it carries.

### protocols/adsl/test/test_uplink.cpp

**reed-solomon**

- beyond 16 errors, detected vs silent miscorrection, counted
- corrects ALL patterns up to 16 symbol errors
- encode then decode with no errors returns 0 corrections

**uplink**

- a header naming a later version or a reserved key is refused
  > E.1: a later version or a reserved key index is a packet this decoder cannot read.
- a length G.3 cannot spell is refused before any decoding
  > A length that names no whole number of records is not an uplink packet, whatever it holds.

- a record with no address and no place on the globe is refused
  > Reed-Solomon can decode to a valid codeword that is not the one that was sent. A ground station reaches every aircraft in range at once, so one miscorrected frame is a screenful of phantoms in front of everybody, and what a frame carries is checked before any of it becomes a target.

  > E.1.3's key index 3 is scrambling switched off, so the data arrives as it was written.

- the sync word is C.4.3's, and the byte behind it is D.1.1's length
  > What the dwell has to be armed with to hear a skyPost at all: C.4.3's two bytes, then the length.
